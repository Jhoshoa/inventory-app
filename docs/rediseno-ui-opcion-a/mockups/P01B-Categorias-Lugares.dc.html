¿Eliminar "Heladera"?

Se quita de 6 productos. Los productos y su stock no cambian; solo dejan de mostrar este lugar.

Por qué aquí

  • Antes estaban en Configuración › Inventario ("Categorías y SKU", "Ubicaciones"). Se usan al cargar productos, así que pasan a Productos. Configuración › Productos guarda solo Vencimientos y atajos a estas pestañas.
  • "Ubicaciones" se llama ahora Lugares en la tienda; en cada producto, Dónde está. "Categorías y SKU" pasa a Categorías.

Caminos

  • Escritorio y tablet: pestañas Productos · Categorías · Lugares en la tienda debajo del título. Rutas /dashboard/products/categorias y /dashboard/products/lugares.
  • Celular: Productos › ⋯ → "Categorías" o "Lugares en la tienda"; pantalla con "Volver a Productos". Crear o editar abre una hoja desde abajo.
  • También desde el formulario del producto ("+ Nueva", "+ Nuevo lugar") y desde Configuración › Productos (atajos).

Validaciones

  • Categoría: nombre requerido (máx. 80), prefijo requerido (máx. 8, solo letras y números, se pasa a mayúsculas). Nombre y prefijo no se repiten (409, en su campo). Cambiar el prefijo no cambia los SKU existentes.
  • Categorías no se borran: se desactivan y dejan de aparecer al crear productos. La API no tiene "volver a activar" (solo /deactivate): "Desactivar…" pide confirmar.
  • Lugar: zona requerida (máx. 50), estante máx. 50, nivel máx. 30 y solo con estante; no se repite sin importar mayúsculas (409). Eliminar avisa a cuántos productos se les quita (product_count).

Permisos

  • Solo dueño. El cajero no ve estas pestañas ni las entradas del menú ⋯; si entra por la URL ve "No tienes permiso". La lista de categorías es solo dueño en la API.
  • El cajero sí ve "Dónde está" de cada producto (en Vender y en el detalle): GET /store-locations acepta cualquier usuario activo.

API (sin cambios)

  • GET/POST /product-categories, PATCH /product-categories/{id}, POST …/{id}/deactivate.
  • GET/POST /store-locations, PATCH y DELETE /store-locations/{id}.
  • Próximo SKU = prefijo + next_sku_number con 6 dígitos. La API no da cuántos productos tiene cada categoría: no se muestra.

Estados

  • Sin categorías: "Crea tu primera categoría para tener SKU automático". Sin lugares: "Todavía no hay lugares" + "+ Nuevo lugar". Error de carga: "Reintentar".
