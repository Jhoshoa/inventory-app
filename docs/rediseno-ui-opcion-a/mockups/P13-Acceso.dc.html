Caminos

  • Entrar → Inicio (dueño) o Vender (cajero, si la caja está abierta; si no, Inicio).
  • Google: siempre pide elegir la cuenta (arreglo ya publicado).
  • Crear tienda → aviso "Revisa tu correo para confirmar la cuenta" si la confirmación está activa; si no, entra directo con la prueba gratis.
  • Invitación → al aceptar, entra a la tienda con el rol de la invitación.

Validaciones

  • Correo: formato válido, máx. 255 (en web y API).
  • Contraseña (crear tienda, nueva contraseña, invitación): mínimo 8, con mayúscula, minúscula, número y símbolo. La lista se marca mientras se escribe y el botón se habilita al cumplir todo.
  • Nombre de tienda y tu nombre: requeridos, máx. 100.
  • "Repite la contraseña": debe ser igual.
  • Demasiados intentos: "Demasiados intentos. Espera unos minutos" (límite de la API, 429).
  • Recuperar: el mensaje es el mismo exista o no la cuenta (no revela correos).

API

  • POST /auth/login, /auth/register, /auth/oauth/google, /auth/forgot-password, /auth/reset-password, GET /user-invitations/preview/{token}, POST /user-invitations/accept — existen.
  • Correos (confirmar, recuperar, invitación): dependen del SMTP con Brevo, pendiente.
  • "Pedir otro en 60 s" y "vence en 1 hora": son los valores por defecto de Supabase Auth; revisar que coincidan con la configuración real antes de mostrarlos.
