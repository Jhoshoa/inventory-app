Etiquetas

  • Celular: 3 pasos (Productos → Diseño → Imprimir) en lugar de una página larga. Escritorio: todo a la vista, en 3 columnas.
  • Cantidad por producto: 1–100 etiquetas. La hoja se recalcula al cambiar tamaño, margen o columnas.
  • "Imprimir" abre el diálogo de impresión del navegador; "Descargar SVG" baja la hoja (como hoy).
  • Llegar desde un producto (QR → "Imprimir etiqueta") lo trae ya elegido (nuevo, solo web).
  • Margen: número en mm (vacío = 8). Tamaños: 20×10, 30×20, 40×25, 50×30, 60×40 y 70×35 mm. Hoja Carta o A4.
  • La configuración se recuerda en este equipo (como hoy).

Importar CSV

  • Solo archivos .csv ("Selecciona un archivo con extensión .csv"), hasta 5 MB y 5.000 filas.
  • Todo o nada: si una fila falla no se crea ninguno; se listan fila, campo y motivo, y se pueden descargar los errores.
  • Reglas por fila: nombre (máx. 100), precio > 0, stock entero ≥ 0, SKU y código únicos, categoría existente, vence/aviso_dias como en el formulario.
  • "Descargar plantilla" usa la exportación de productos actual.

Permisos

  • Etiquetas e importar: solo dueño.

API

  • GET /products, POST /products/import, GET /products/import/{job_id}, GET /exports/products.csv — existen. Sin cambios.
