Plan y pagos

  • La tarjeta de arriba cambia según el estado: Prueba (días que quedan), Activo (próximo pago), En gracia (días para pagar), Suspendido (solo ver y pagar).
  • "Pagar por WhatsApp" registra la solicitud de pago y abre WhatsApp (como hoy, "Pagar ahora por WhatsApp").
  • El historial es el registro de cambios del plan (quién y cuándo), no facturas.
  • No se muestra precio: la API no lo entrega. Si se quiere mostrar, agregarlo a la configuración del sitio (web) o a /billing/status (opcional).

Mi perfil

  • Correo solo lectura. "Cambiar" contraseña manda el correo de recuperación (POST /auth/forgot-password) — depende del SMTP (Brevo).
  • Usuarios de Google: sin opción de contraseña.
  • "Cerrar sesión": mismo cierre de hoy; al volver a entrar con Google se elige la cuenta.

Datos de la tienda — validaciones

  • Nombre: requerido, máx. 100. Dirección: máx. 255. Teléfono: +591 por defecto, solo números (8 dígitos en Bolivia).
  • Zona horaria: solo lectura (cambiarla movería los días de venta).
  • "Descartar" vuelve a lo guardado; salir con cambios pide confirmación.

Permisos

  • Configuración completa: solo dueño. El cajero solo tiene Mi perfil (desde Más).

API

  • GET/PATCH /store, POST /store/storefront-logo, GET /billing/status, GET /billing/history, POST /billing/checkout, GET /auth/me — existen. Sin cambios.
