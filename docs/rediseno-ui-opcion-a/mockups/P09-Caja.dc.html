Caminos

  • Escritorio: menú Caja. Celular: Más → Caja y jornada (y la tarjeta de Inicio). La página nueva junta lo que hoy está en Ajustes › Operación diaria.
  • Vender con la caja cerrada muestra el estado cerrado con "Abrir caja" (dueño).
  • Al cerrar: aviso "Caja cerrada" y se abre el resumen del cierre (Reportes › Cierres).

Validaciones

  • Montos (apertura, movimiento, contado): solo números, hasta 2 decimales, máx. 12 dígitos, no negativos. Movimiento: mayor a 0. Apertura y contado: pueden ser 0.
  • Aceptar coma o punto como decimal ("30,50" o "30.50") y enviar con punto. Hoy la web solo acepta punto; en Bolivia se escribe con coma.
  • Notas de apertura, cierre, reapertura y movimiento: máx. 255.
  • Cerrar: o se escribe el efectivo contado o se elige "Cerrar sin contar" (no ambos).
  • Anular movimiento: razón requerida (la API la exige; hoy la web dice "opcional", hay que corregirlo).
  • Movimientos y anulaciones solo con la caja abierta.

Reglas de la API que se muestran

  • "La tienda ya tiene una jornada abierta"; si hoy ya se cerró, no se abre otra: se reabre la de hoy.
  • Tipos: Entrada (entra) · Salida, Gasto, Retiro, Depósito al banco (salen).
  • Debería haber = apertura + ventas en efectivo + entradas − salidas.

Permisos

  • Abrir, cerrar, reabrir y movimientos: solo dueño. Cajero: ve si está abierta, sin montos ni botones.

API

  • GET /store-day/current, /current/closing-preview, /current/events, POST /store-day/open, /close, /reopen, POST /cash-movements, GET /cash-movements, POST /cash-movements/{id}/void — existen.
  • "Igual que ayer": monto de apertura del último cierre (GET /store-day/reports, solo web).
