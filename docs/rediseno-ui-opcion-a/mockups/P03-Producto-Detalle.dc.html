Caminos

  • "Ajustar stock" → ventana con dos pestañas: Agregar (con lote opcional) y Descontar (elige lote o automático).
  • "Retirar" en un lote → la misma ventana en "Descontar" con ese lote y la cantidad que queda.
  • "Cambiar" en Dónde está → ventana "Dónde está" (elige lugares o crea uno con "+ Nuevo lugar"). ⋯ → Ver QR, Duplicar (nuevo), Eliminar.
  • "Ver todos" movimientos → Reportes › Movimientos de stock filtrado por este producto.
  • Al guardar cualquier cambio: aviso arriba ("Stock actualizado") y la página se refresca sin perder la posición.

Reglas que se ven

  • Estado del stock: Sin stock (0), Bajo (≤ mínimo), Disponible.
  • Lotes: Vencido, Por vencer (dentro del aviso), Vigente; los agotados no se listan.
  • "En el catálogo": producto activo y catálogo encendido.
  • "Ganas … con descuento" = precio efectivo − costo (solo si hay costo).

Permisos

  • Cajero: ve todo menos costo y margen; sin botones Ajustar, Editar, Retirar, Cambiar ni ⋯ (queda "Ver QR").

API

  • GET /products/{id} (con locations), GET /products/{id}/batches, GET /products/{id}/stock-movements — existen.
  • Ocultar el costo al cajero: hoy la API se lo devuelve; se oculta en la web. Si debe quedar oculto de verdad, backend B5 (opcional): no enviar cost_price a cajeros.
  • Duplicar: la web abre "Nuevo producto" con los datos copiados (sin SKU ni código). Sin backend.
